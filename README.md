Nand2Tetris

This repository contains my work for the Nand2Tetris course (also known as The Elements of Computing Systems).
The goal of this project is to understand how a complete computer system is built from the ground up — starting with simple logic gates and ending with a working computer capable of running programs.

About the Project

Nand2Tetris is a hands-on course where we build:
1) Logic gates using NAND
2) Arithmetic and memory components
3) A simple CPU
4) An assembler
5) A virtual machine
6) A high-level language and compiler
7) An operating system (basic)

Learning Outcomes

Through completing this project, I was able to:
1) Gain a strong understanding of how computers work at a fundamental level
2) Understand the relationship between hardware and software abstractions
3) Improve problem-solving skills by building systems step by step
4) Become comfortable working with low-level components and abstractions
